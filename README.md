# Rhino Siteworks

Custom Next.js website for Rhino Siteworks.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm start
```

## Required image files

Place the approved project photos in `public/images/` using these names:

- `project-hero.webp`
- `project-18.webp`
- `project-19.webp`
- `project-20.webp`

The layout, responsive styling, service content, contact links, metadata, and image placements are already configured.
